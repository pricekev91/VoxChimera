- `tests/test_main.py` — placeholder pytest tests for all three pipeline stubs
- `docs/architecture.md` — high-level system design and component descriptions
- `docs/decisions.md` — ADR template, ADR 001 (repo isolation), ADR 002
  (technology stack)

  Commits, code style, ADR workflow
- `CODE_OF_CONDUCT.md` — lightweight solo-friendly conduct policy
- `CHANGELOG.md` — this file
- `README.md` — full project overview, tech stack, getting started, folder
